My Projects

Enhanced Audio Steganography for Secure Data Transmission

This was my final year major project developed using ASP.NET to provide secure communication through audio steganography. The system hides confidential information inside audio files without affecting the original sound quality, ensuring secure and invisible data transmission.

To improve security, the hidden message is encrypted using the Triple DES (3DES) algorithm before being embedded into the audio file. This provides two layers of protection: encryption and steganography, making unauthorized access to the hidden message significantly more difficult.

The application allows users to securely embed and extract secret messages while maintaining data integrity and audio quality. This project enhanced my practical knowledge of ASP.NET programming, encryption techniques, file handling, cybersecurity concepts, and secure application development.
